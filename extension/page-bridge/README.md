# Desktop Assistant Page Bridge

A Chrome extension that lets the Desktop Assistant app on this Mac read and operate the page in the active tab from inside the browser. Reading a page this way takes tens of milliseconds; reading it through macOS accessibility takes one to two seconds.

## Install

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose this folder (`extension/page-bridge`).
4. Start the Desktop Assistant app. Within about 30 seconds the overlay's **Settings and connection** shows "Chrome page bridge: connected". Clicking the extension's toolbar button reconnects at once.

Keep the extension id as Chrome shows it: `fnkgdiiboieohdmillkacfkpfgidnfmf`. The app answers only that id.

After the files in this folder change, press the reload arrow on the extension's card in `chrome://extensions`. Chrome keeps running the old copy until then. The app does not use a copy older than it expects, and its settings say so.

## What it can do, and what it is allowed to do

- It can read and change every page you have open in this Chrome profile, including sites you are signed in to. That is what makes it useful and it is also the risk. Remove it from `chrome://extensions` at any time.
- It talks only to `http://127.0.0.1:8767`, the app on this Mac. It sends nothing anywhere else and stores nothing.
- It does nothing by itself. It asks the app for one command at a time and runs only: read the active tab, perform one operation on one element, open an address, switch tab.
- It never reads the value of a password field and never types into one.
- The app refuses requests that do not come from this extension's origin, which a web page cannot forge. Another program running on this Mac under your account could pretend to be the extension; such a program already has your account's access.

## Limits

- Browser pages (`chrome://…`), the Chrome Web Store and the PDF viewer cannot be read; the app falls back to accessibility for them.
- Embedded frames are not read yet; the page reports how many it skipped.
- A page over 4,000 items is listed up to that limit, plus anything further down that matches the current search.
- Clicks and keys are generated by script. A few sites ignore those; the app's ordinary accessibility route still exists for them.
- Chrome only. Safari needs a separately packaged extension.

## Test

`npm run test:extension` loads this extension into a separate Chromium (never your Chrome or its profile) and drives a local fixture page through the app's bridge code. If Playwright's own Chromium is not installed for this Playwright version, point `PAGE_BRIDGE_CHROMIUM` at any Chromium or Chrome for Testing binary.
